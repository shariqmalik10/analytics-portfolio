Sales and subscription analytics in Tableau

I built the reporting for a point-of-sale platform used by car service centres and garages in Saudi Arabia: Tableau Prep flows that read the production SQL Server database, and dashboards in Tableau Desktop and Tableau Cloud that track customers, orders, revenue and subscriptions.

The originals were built in Tableau and can’t be shared for data-privacy reasons. The figures on this page redraw them with dummy data, and the company is called Motorly here.

Tableau Desktop · Tableau Prep Builder · Tableau Cloud · Microsoft SQL Server

The data behind it

Three Tableau Prep flows read the production SQL Server database, and their outputs were published to Tableau Cloud.

Orders by location

Locations joined to users, then orders, then checkout records fetched with custom SQL. The output has one row per order: location, country, date, year, order and checkout IDs, and grand total.

Car analytics

Cars joined to the cars-to-locations table on CarID, then to locations and users, and aggregated into the Car_Analytics output.

Subscriptions

User package details joined to users, cleaned, and aggregated by subscription type and business type as a count of distinct users.
